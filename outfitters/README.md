# OUTFITTERS — React Fashion Store

A complete React fashion storefront built with JavaScript files (JS + JSX syntax), with no extra router dependency.

## Run
```bash
npm install
npm start
```

## Production build
```bash
npm run build
```

## Included
- Original first-page hero structure retained.
- Announcement marquee.
- Working Home, Shop, Collections, New Arrivals, Best Sellers and Sale navigation.
- Category filtering and sorting.
- 12 different product images.
- Product details pages with size selection and quantity.
- Wishlist stored in localStorage.
- Shopping cart stored in localStorage.
- ₹199 shipping below ₹999 and free shipping at/above ₹999.
- Checkout with GPay / Paytm / Card demo options. No real payment is processed.
- Search overlay.
- Contact, About, FAQ, Shipping and Account pages.
- Responsive mobile layout.

Product/editorial photos use remote Unsplash image URLs; replace those URLs with your own licensed product photography before a commercial launch.
